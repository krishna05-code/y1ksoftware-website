Web app FAQs

Questions before scoping

What is the difference between a website and a web application?

A website mainly presents information, while a web application typically lets users sign in, manage data, or complete an ongoing workflow.

Can a web app include different user roles?

Yes. Role-specific access and actions can be planned when the users and permission rules are clearly defined.

Can it use an existing database or API?

Possibly. We first review the interface, data model, security requirements, documentation, and technical constraints.

How should I describe the project?

Explain who will use it, the steps they take today, the information involved, the problems to remove, and the outcome you want.
